# Color Palette from Woodful Creations Logo

## Primary Colors
- **Deep Brown**: #6B4423 (Main brand color - from wood grain)
- **Black**: #000000 (Strong contrast - from saw blade)
- **Light Brown/Tan**: #A0826D (Accent - lighter wood tone)
- **Warm Beige**: #D4C4B0 (Background/secondary)

## Extended Palette
- **Success Green**: #2D5A2D (For positive actions)
- **Alert Orange**: #E67E22 (For warnings/low stock)
- **Error Red**: #C0392B (For errors/critical alerts)
- **Text Dark**: #2C2C2C (Main text - almost black)
- **Text Light**: #F5F1EB (Light backgrounds)

## Usage
```
Primary Actions: Deep Brown (#6B4423)
Text: Text Dark (#2C2C2C)
Accents: Light Brown (#A0826D)
Backgrounds: Warm Beige (#D4C4B0)
Borders: Black (#000000)
Success: Success Green (#2D5A2D)
Warning: Alert Orange (#E67E22)
Error: Error Red (#C0392B)
```

## Tailwind CSS Configuration
```js
colors: {
  'woodful': {
    'dark': '#6B4423',
    'black': '#000000',
    'light': '#A0826D',
    'beige': '#D4C4B0',
    'cream': '#F5F1EB',
  }
}
```

## Light & Dark Mode

### Light Mode
- Background: #F5F1EB (Cream)
- Text: #2C2C2C (Dark)
- Borders: #A0826D (Light Brown)

### Dark Mode
- Background: #2C2C2C (Dark)
- Text: #F5F1EB (Cream)
- Borders: #6B4423 (Deep Brown)
